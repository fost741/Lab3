# Практична робота №3: Конструктори та перевантаження (Overloading)
## Предметна область
Програма моделює предметну область **«Музичні інструменти»** (`Instruments`).

### Кожен об'єкт класифікується за:
* **назвою** (`name`) та **брендом** (`brand`): *Yamaha, Gibson, Pearl, Roland*.
* **сімейством** (`family`): *Strings, Woodwinds, Brass, Percussion, Keyboard*.
* **типом живлення**: акустичний або електронний (`isElectric`).
* **кількісними параметрами**: кількість струн (`stringCount`) та клавіш (`keyCount`).
* **поточним станом**: підключення до мережі (`isConnected`), налаштованість (`isTuned`) та рівень гучності (`currentVolume`).

## **Мета роботи**
- Навчитися створювати конструктори класу;
- Ознайомитися з перевантаженням конструкторів класу;
- Набути навичок перевантаження методів класу, що реалізують його поведінку.

## 1. **Конструктори класу `Instruments`:**
* **Конструктор за замовчуванням (без параметрів):** ініціалізує об'єкт стандартними значеннями з використанням ініціалізаторів.
   * **Перевантажені конструктори з параметрами:** реалізовано декілька конструкторів з різною сигнатурою.
   * **Виклик власного конструктора (`this`):** реалізовано ланцюжок конструкторів (виклики одного конструктора з іншого).
   * Під час виклику будь-якого конструктора користувач отримує консольне повідомлення про те, який саме конструктор спрацював для створення об'єкта.

## 2. **Перевантаження методів поведінки:**
* Для `public`-методу регулювання гучності (`SetVolume`) реалізовано декілька перевантажених версій із різною сигнатурою:
     * **Стандартний режим:** встановлення конкретного рівня гучності (0–100%).
     * **Режим плавної зміни (Fading Out):** коригування гучності за часом і тривалістю.
     * **Режим за типом приміщення:** коригування гучності залежно від типу залежності (`concert hall`, `studio`, `home`).

## 3. **Консольне меню:**
   * `1 – Add object`: створення інструментів різними конструкторами (зокрема ручне введення або за допомогою випадкового вибору конструктора).
   * `2 – Show all objects`: форматоване відображення списку інструментів у вигляді таблиці.
   * `3 – Search object`: пошук за вказаними критеріями (назва, родина тощо).
   * `4 – Show behaviour`: демонстрація роботи  методів (перевантажений `SetVolume`, `Tune`, `Play`, `Connect`).
   * `5 – Delete object`: вилучення вибраного інструмента зі списку.
   * `0 – Exit`: закриття застосунку.
